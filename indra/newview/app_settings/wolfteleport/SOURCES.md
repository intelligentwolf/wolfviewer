# WolfViewer teleport sounds: where they come from

Every sound in this folder was made for WolfViewer from scratch by
`scripts/wolfteleport/make_sounds.py` in this repository: sine tones, filtered noise and
envelopes only. No recording, sample or sound from anywhere else is in them. That script is the
exact recipe; run it to make them again (it needs Python 3 with numpy and scipy, and ffmpeg).

| File | Name in Wolf World > Sound Effects |
|---|---|
| wolf_tp_shimmer.ogg | Soft shimmer |
| wolf_tp_whoosh.ogg | Gentle whoosh |
| wolf_tp_chime.ogg | Crystal chime |
| wolf_tp_warp.ogg | Warp |
| wolf_tp_sparkle.ogg | Magic sparkle |
| wolf_tp_pop.ogg | Quiet pop |
