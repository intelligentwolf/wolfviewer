# WolfViewer

**WolfViewer** is the desktop viewer for the [Wolf Territories Grid](https://www.wolf-grid.com), an OpenSimulator world. It is free and open source, built by [IntelligentWolf Ltd](https://wolf.uk.com) for Windows, macOS and Linux.

## Download

Ready-made builds for all three platforms are on the grid's [Get a Viewer](https://www.wolf-grid.com/index.php?f=osv) page. Release notes are on the [GitHub releases](https://github.com/intelligentwolf/wolfviewer/releases) page.

New to the grid? [Join here](https://www.wolf-grid.com/index.php?f=newuser).
